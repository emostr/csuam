# ЦСУАМ "Архивли"

Цифровая система управления архивными материалами школы "Архивли"

Платформа для долгосрочного хранения, систематизации и учёта школьных материалов: наград, фотографий, видео, библиотеки и архивных документов.

## Стек

- Фронтенд: Vue 3, TailwindCSS, sweetalert2-neutral, Chart.js (на основе собственного шаблона NightingaleUI-template-Vue — https://github.com/emostr/NightingaleUI-template-Vue)
- Бэкенд: Go + Chi + sqlc (pgx)
- СУБД: PostgreSQL
- Хранилище файлов: S3-совместимое (MinIO)
- Сервер: Debian 13 Trixie, NGINX, Docker

## Возможности

- Пять категорий материалов: награды, фотографии, видео, библиотека, документы;
- Многофункциональный поиск: по ключевым словам, времени происхождения, категориям;
- Аналитика: всего единиц, соотношение по категориям, динамика добавления;
- Карточка экспоната: просмотр файла прямо на портале, состояние, местонахождение физического экземпляра, время происхождения и добавления;
- QR-код со ссылкой на карточку, которую можно распечатать и наклеить на физический экземпляр;
- Экспорт/импорт карточек в JSON и XML;
- Встроенный текстовый редактор: WYSIWYG и Markdown; такие документы хранятся в БД;
- Прокат: учёт выданных книг, срок возврата, уведомление о просрочке, архив возвратов;
- Разделение ролей:
  - Завуч — полный доступ, включая управление пользователями;
  - Библиотекарь — полный доступ, кроме "Документов" (открываются избирательно по решению завуча), может вести прокат и модерацию;
  - Учитель — добавляет материалы (премодерация).

## Поддерживаемые форматы файлов

PDF, DOC, DOCX, PPT, PPTX, ODT, ODP, PNG, JPG, GIF, SVG, BMP, WEBP, MP4, MP3, WAV, WMV, WEBM, HTML, MD.

Изображения, видео, аудио, PDF, HTML и Markdown-файлы открываются прямо на платформе. Файлы DOC(X), PPT(X), ODT и ODP предлагаются к скачиванию.

## Запуск в Docker

```bash
cp .env.example .env
docker compose up -d --build
```

Не забудьте подставить свои значения переменных в .env. 

Платформа будет доступна по адресу http://localhost:8000. Изменить порт можно через переменную окружения "HTTP_PORT".

При первом запуске автоматически применяются миграции и создаются пользователи "zavuch" (завуч), "librarian" (библиотекарь) и "teacher" (учитель). Пароли по умолчанию берутся из переменных окружения SEED_HEAD_TEACHER_PASSWORD, SEED_LIBRARIAN_PASSWORD и SEED_TEACHER_PASSWORD. После первого входа требуется смена пароля в настройках.

## Запуск в проде

1. Установите Docker и NGINX;
2. Запустите "docker compose up -d --build";
3. Скопируйте файл "nginx/example.com.conf" в папку "/etc/nginx/sites-available/". Получите SSL-сертификат (certbot --nginx -d example.com), перезагрузите NGINX.

## Разработка

Бэкенд (Go 1.23+):

```bash
cd backend
go mod tidy
go run ./cmd/server
```

Фронтенд (Node 20+):

```bash
cd frontend
npm install
npm run dev
```

Дев-сервер Vite проксирует /api на localhost:8080. PostgreSQL и MinIO нужно запускать из compose: docker compose up -d postgres minio

SQL-запросы описаны в backend/queries/ в формате sqlc, конфиг backend/sqlc.yaml, схема в backend/internal/migrate/sql/. Миграции применяются автоматически при старте.
